# ملفاتي — Malafaty

> مساحة عمل خاصة لحفظ الملفات والملاحظات، بتصميم يوازي واجهات العيادات العالمية،
> مع **قاعدة بيانات `localStorage`** وتسجيل دخول **بالبريد وكلمة المرور**،
> و**عزل تام** بين كل مستخدم وآخر.

## 🗃 محتويات المستودع

```
index.html              موقع «ملفاتي» — الصفحة الرئيسية المنشورة
assets/css/style.css    نظام التصميم (Design tokens · RTL · متجاوب)
assets/js/crypto.js     الطبقة التشفيرية  — PBKDF2 + AES-256-GCM
assets/js/db.js         قاعدة البيانات     — localStorage schema + عزل المفاتيح
assets/js/auth.js       المصادقة           — تسجيل/دخول/جلسة/تغيير كلمة المرور
assets/js/ui.js         عناصر الواجهة      — Toast · Modal · Confirm
```

> يعمل مباشرة بفتح `index.html` أو عبر أي استضافة ثابتة.

## 🗄 نموذج قاعدة البيانات (localStorage)

```
mfy:meta                     معلومات المخطط
mfy:users                    [{ id, email, name, salt, passHash, ... }]
mfy:session                  { userId, token, issuedAt, expiresAt }
mfy:data:<userId>            { files:[], notes:[], prefs:{} }
```

**الضمانة الأمنية:** بيانات كل مستخدم مخزّنة تحت مفتاح خاص به `mfy:data:<id>`،
ولا تُقرأ إلا بعد التحقق من أن جلسة الدخول (التوكن) تخصّ نفس الـ `userId`.
أي محاولة وصول لمستخدم آخر تفشل على ثلاث طبقات:

1. **طبقة الجلسة** — `getSession()` يرفض التوكن غير الصحيح أو منتهي الصلاحية.
2. **طبقة المفتاح** — لا يمكن قراءة `mfy:data:<id>` إلا بمرور `session.userId` المُتحقَّق منه.
3. **طبقة المحتوى** — كل نص وصورة مشفّر بـ AES-256 بمفتاح مشتق من كلمة المرور
   (PBKDF2‑SHA256 بـ 160,000 دورة)، والمفتاح **لا يُخزَّن إطلاقاً** بل يبقى في ذاكرة الجلسة فقط.

> النتيجة: حتى لو فتح أحدهم `localStorage` يدوياً، يرى نصوصاً مشفّرة فقط.

## ▶️ التشغيل

### محلياً
افتح `index.html` مباشرة في المتصفح — أو شغّل خادماً بسيطاً:

```bash
npx serve .
# أو
python -m http.server 8080
```

1. ارفع الملفات إلى المستودع.
2. **Settings → Pages → Source: Deploy from a branch → `main` / root → Save**.
3. بعد دقيقة يصبح الموقع على:
   `https://<username>.github.io/<repo>/`

## ⚠️ ملاحظات مهمة

- **لا تُخزَّن كلمة المرور أبداً** — يُخزَّن فقط `salt` + `passHash` مشتق عبر PBKDF2.
- **لا يمكن استرجاع المحتوى إن نسيت كلمة المرور** لأن المفتاح مشتق منها ولا يُحفظ.
- بيانات `localStorage` خاصة **بالجهاز والمتصفح**؛ مسح بيانات المتصفح يحذفها.
  استخدم زر **تصدير نسخة احتياطية** في صفحة الحساب دورياً.
- هذا تطبيق **client‑side بالكامل** — لا خوادم ولا رفع إلى الإنترنت.
